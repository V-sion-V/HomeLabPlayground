## 3. 影响分析与全局设计

- **契约与持久化**：扩展全局扑克设置、牌局准备集合和结果摘要；构造领域对象时兼容缺失新字段的旧快照。结算摘要保存签名净变化及仅在真实摊牌时可公开的牌面/牌型。
- **服务端状态机**：移除完整结算后的自动下一手定时器和外部房主“下一手”命令，新增任何在座玩家可调用的幂等版本化准备命令。断线清除该玩家准备；零筹码或断线座位阻塞；最后一个有效准备或移除阻塞座位后原子开始下一手。
- **投影与隐私**：常规进行中投影仍只向本人发送手牌；只有已持久化的真实摊牌摘要向所有角色公开未弃牌玩家手牌。弃牌、牌堆和非摊牌牌面不得进入结果投影。
- **客户端**：统一牌面组件和花色主题；重排牌桌顶栏；窄屏座位改为页面内横向滚动并约束所有网格子项；倒计时使用 CSS transform 动画和局部 DOM 文本更新；complete 阶段显示玩家/大屏共用结算面板。
- **恢复与并发**：准备集合随牌局持久化；服务重启会把连接和准备恢复为未准备，避免无人在线时自动开局。准备、离开/移除、补码和下一手启动继续由平台版本事务串行化。
