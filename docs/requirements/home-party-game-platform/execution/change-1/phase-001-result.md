## 1. 阶段目标与结果

P-001 完成了 RC-1-001–RC-1-005。玩家牌桌可在 300px 手机竖屏内使用且没有页面级横向溢出；牌桌顶部改为左侧返回、中间房间名与当前玩家名、右侧语言和静音。全局设置新增标准与高对比度两种花色预设，并统一作用于玩家端和公共大屏。

倒计时进度改为浏览器合成的 `transform` 连续动画，数字文本由局部 `requestAnimationFrame` 更新，不再以高频 React 状态刷新重绘整桌。结算完成后不再自动发下一手，而是保留玩家端和大屏共用的悬浮结算面板，显示全部参与者的签名筹码净变化；真实摊牌时只公开未弃牌摊牌玩家的手牌、赢家和赢家牌型。

每个仍占座玩家都必须在结算面板准备。断线或零筹码座位会阻止下一手，直到玩家重连并重新准备、补码后准备、离开，或由房主移除；最后一个有效准备命令在同一权威事务内创建下一手。
