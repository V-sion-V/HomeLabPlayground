## 3. 影响分析与全局设计

- **契约与持久化**：为新结算结果的玩家摘要保存 `endingChips`。字段在共享投影中保持可选，以兼容 change-1 已持久化、尚无该字段的旧结果；新结果必须写入非负整数。
- **显示语义**：结算玩家仍在房间时，界面优先显示座位投影的实时 `tableChips`，因此补码后总量立即更新；玩家已离座时回退到结果快照的 `endingChips`。旧结果两者都缺失时显示不可用占位，不伪造数值。
- **弹窗层级**：把 `TopUpModal` 从 `.action-dock` 堆叠上下文移到牌桌根级兄弟节点，保留现有 modal 的焦点、关闭和提交行为，不提升整个操作区层级。
- **验证**：服务测试证明新结果保存/投影结算后总筹码；生产浏览器 E2E 证明结算行显示增减与总量，并能从被覆盖场景实际填写、确认补码。
