## 1. 当前目标与范围

本功能把可信家庭局域网中的危险平台设置和数据管理从玩家流程分离到匿名直达的管理员
应用，同时把语言、亮暗主题和音量升级为服务器权威账户偏好。登录采用只读查询、
existing-only 进入和 create-only 注册；管理员可原子保存平台默认值、批量删除账户和
历史赛季，并在开放房间中安全处理被删成员、房主、筹码、租约和历史匿名化。

当前范围还统一了固定面板、modal、内部滚动槽、共享 SVG 箭头和通过 body portal
定位的头像操作菜单，并在 `docs/ui-design-guidelines.md` 固化可复用规则。全部行为需要
同时支持简体中文/英文、桌面、300px 窄屏、键盘、触控、SQLite 恢复、离线容器和既有
公共/私有投影边界。

不包含密码、互联网身份或真正的管理员认证，不包含账户删除撤销、应用内备份恢复、
扑克规则变化、新游戏、数据库引擎替换或运行时公网依赖。`/admin` 的匿名写入只适用于
可信 LAN，产品仍不得暴露到公网。正式部署继续使用既有部署自动化，不属于本需求本身。

## 3. 当前用户与管理流程

### 3.1 已有账户进入与新账户注册

1. 用户在首屏提交用户名；服务器只读返回规范化显示名和是否存在，不创建或更新账户。
2. 已有账户通过 existing-only 请求取得租约，客户端应用该账户的语言、主题和音量，再
   恢复原房间或进入大厅。
3. 新用户名进入注册页；用户按需展开头像并选择语言和主题。
4. create-only 注册在服务器事务内重新检查用户名；并发占用明确拒绝，成功则创建账户、
   当前赛季资产和租约，音量初始为 `100`。

### 3.2 账户资料

1. 玩家从大厅唯一账户入口打开资料。
2. 用户编辑用户名、头像、语言、主题和音量。
3. 一次保存以有效租约、命令 ID 和期望版本原子提交五个字段。
4. 成功后当前客户端立即应用偏好；刷新、接管或重启继续从服务器账户恢复。

### 3.3 管理员设置

1. 可信 LAN 用户直接访问 `/admin`；管理员设备语言和主题只改变本地管理员外观。
2. 通用列编辑默认语言、默认主题和房主转让秒数；扑克卡片编辑现有扑克默认值。
3. 一个保存命令携带命令 ID 和期望版本；服务端重新校验全部字段并原子提交。
4. 版本冲突、非法值或持久化失败整体拒绝，客户端重新获取最小管理投影。

### 3.4 账户批量删除

1. 管理员在 `/admin/accounts` 选择任意账户集合并确认不可逆影响。
2. 服务端在事务内重新解析账户、房间、在线状态、房主候选和权威资产。
3. 普通成员按活动手或等待状态移除；被选房主转让给未选在线成员，否则安全关闭房间。
4. 全部房间处理、资产退役、历史匿名化、租约失效和活动账户删除一起提交并广播。
5. 批次可使活动账户集合为空；随后可按当前赛季和全局默认值注册全新账户。

### 3.5 赛季管理

1. `/admin/seasons` 展示禁选的 current 和可复选的历史赛季。
2. 历史删除在没有开放房间时原子清理所选关联数据；空选择不写入。
3. 开始新赛季经二次确认原子归档 current，并按指定名称和基础分初始化新 current。

## 4. 当前数据、接口与状态

- `Account` 持久化 `language: "zh-CN" | "en"`、`theme: "light" | "dark"` 和整数
  `volume: 0..100`；它们与用户名、头像和 `updatedAt` 在同一资料事务中更新。
- `GlobalSettings` 持久化 `defaultLanguage`、`defaultTheme`、正整数房主转让秒数和现有
  扑克默认值。新安装默认简体中文和深色；默认值只初始化新账户和无账户界面。
- 旧 SQLite JSON 只为缺失字段补值：账户使用升级后全局语言/主题和音量 `100`，全局
  主题补 `dark`；已有合法偏好、账户、资产、房间、手牌、排行榜、头像和花色不被覆盖。
- 服务重启恢复已确认业务状态，但清除全部旧控制租约；已删身份和已失效会话不复活。
- 账户 API 分为只读 `POST /api/account/lookup`、existing-only `POST /api/enter` 和
  create-only `POST /api/register`。资料修改继续要求有效账户租约。
- 管理员使用 `GET /api/admin/state` 取得最小投影，使用
  `POST /api/admin/command` 发送 `admin.settings.update`、
  `admin.accounts.delete`、`admin.seasons.delete` 或 `admin.season.start`。
- 管理员写入不要求账户租约，但必须带命令 ID 和期望平台版本，并受 Zod、领域不变量、
  幂等结果和 `PlatformStore.execute()` SQLite 单事务约束。
- 管理投影只含设置、账户摘要、赛季摘要和必要版本；不含连接令牌、隐藏牌、完整流水、
  私有房间投影或退役身份内部映射。
- 账户删除输入是服务端去重并重新解析的账户 ID 集合；客户端不能指定房主候选、退款额
  或执行顺序。删除后的稳定匿名身份不保存可逆用户名或头像。
- WebSocket/HTTP 继续按公开大厅、本人房间和匿名 display 投影广播；账户偏好不进入其他
  玩家或公共大屏投影，隐藏牌只进入本人有效控制租约。
- 管理员路由通过 History API 与地址同步；刷新、前进和后退恢复 `/admin`、
  `/admin/accounts` 或 `/admin/seasons`，并且不会恢复玩家会话。
- 管理员设备键与玩家旧键、账户数据和全局设置隔离。普通玩家流程不再读写
  `party-language` 或 `party-theme` 作为账户偏好。

## 5. 异常、并发与恢复边界

- `/admin` 是刻意采用的匿名可信 LAN 接口，不得描述为有认证的权限系统，也不得公网
  暴露。危险操作在 UI 中明确标记，但真正保护来自服务端版本、幂等和领域校验。
- 用户名查询只是时点事实；注册会重新校验，竞态用 `USERNAME_TAKEN` 或等价稳定代码
  拒绝。已有账户进入不接受偏好字段，不能借登录覆盖资料。
- 管理保存、账户集合删除和赛季集合删除遇到目标变化、过期版本、非法输入、不变量失败、
  并发或 SQLite 异常时回滚完整事务；相同幂等键只重放原结果。
- 活动手中被删普通成员的已下注筹码留池，未投入栈和非当前手筹码正确兑换；房主不会
  转让给同批次目标或离线成员。
- 历史赛季删除仍被任何开放房间阻止；账户删除允许处理开放房间，两者不能共用会放宽
  赛季门禁的客户端判断。
- 固定容器在空、短、长、错误、下拉、头像和嵌套确认内容下都保持顶/底栏可达；头像菜单
  在边缘视口安全换向或约束，并在目标或权限变化时关闭。
- 音量缺失、`NaN`、非整数或越界由服务端拒绝；音量 `0` 不创建可听输出。音频错误与
  游戏状态、命令和恢复隔离。
- 新代码无法健康启动时仍依赖既有部署自动化和 SQLite 整库备份恢复；不得删除命名卷、
  固定备份或未知恢复现场。本功能的隔离环境验收不构成正式发布。

| AC-016–AC-017 | core | 固定三段容器、稳定滚动槽、无页面横向溢出及 body portal 头像菜单成立。 |

当前 initial 以 `relaxed` 策略交付，但全部 core、硬门禁和 supplemental 验收均实际通过；
没有豁免、验收降级或开放 finding。

## 8. 生效决策

- 管理员三条路由匿名直达且主界面没有入口；这是可信 LAN 模型，不是认证。
- “主题”只表示现有 `light`/`dark`；玩家值随账户保存，管理员值使用独立本地键。
- 全局语言和主题只初始化新账户；已有账户进入永远读取服务器偏好。
- 登录分为只读查询、existing-only 进入和 create-only 注册；并发同名注册拒绝。
- 注册和资料头像均按需展开；音量是账户级整数 `0–100`，新旧缺失值为 `100`。
- 管理员可删除最后一个或全部账户，无发起者保护；开放房间中的目标按权威退出、房主
  转让或安全关房语义处理，完整批次原子提交。
- current 赛季禁选，历史赛季删除仍要求无开放房间；新赛季只从管理员赛季页发起。
- 所有导航/状态箭头使用 SVG；全部 modal、弹层和固定面板采用固定外框、锁定顶底栏和
  稳定内部滚动槽；头像菜单用 body portal。
- 账户和全局设置继续存入现有 SQLite JSON 快照，没有新增 SQL migration、数据库引擎
  或运行时依赖。
- 正式部署不属于本需求；initial 只完成用户授权的真实 iStoreOS 隔离容器和浏览器验收，
  未切换正式容器、固定卷、发布目录或唯一备份。

## 9. 已替代行为

- 玩家大厅的全局设置、账户/赛季管理、新赛季、独立语言和独立主题入口已被移除。
- 旧的“进入或创建并可顺带更新头像”混合意图已被只读查询、existing-only 和
  create-only 三段边界替代。
- `party-language`、`party-theme` 不再是玩家账户偏好的长期权威；合法偏好来自账户。
- 注册页和资料页初始平铺全部头像的行为已被按当前头像展开选择替代。
- 固定的 30/60/120 秒房主转让选项已被服务端校验的正整数输入替代。
- 逐项账户/赛季删除按钮已被复选、全选和单一确认操作替代。
- Unicode 控件箭头、整体 modal 滚动和嵌套座位层级中的头像菜单已分别被共享 SVG、
  固定三段容器和 body portal 替代。
